# DeepEyeUnlocker v4.7.2 - The "Cyber Sentinel" Build

**Release Date:** 2026-02-10
**Focus:** UI Overhaul & Deployment Stability

## ⚡ New Power Features

### 1. Cyberpunk Icon Suite (Android)

- **What it does:** Replaces standard Android assets with premium, high-contrast cyberpunk-themed icons and foreground drawables.
- **Aesthetic:** Neo-Teal (#00FFD4) on Obsidian Black.
- **Impact:** Enhanced visual identity for the "Pro" mobile experience.

### 2. Desktop Remote Server Hub

- **What it does:** Enables the DeepEye Desktop client to act as a remote server for OTG operations.
- **Workflow:** Connect a device via OTG on Android, and control/flash it from your Desktop using the new Remote Hub.
- **Capability:** Secure, end-to-end encrypted protocol tunneling.

### 3. Build & CI Hardening

- **Fix:** Resolved a missing reference in the Windows build pipeline that prevented successful compilation of the desktop client.
- **Cleanup:** Removed deprecated "Watermark" helper logic that was causing linker errors.
- **Stability:** Updated Android Gradle wrapper and core components for better compatibility with target SDK 34.
